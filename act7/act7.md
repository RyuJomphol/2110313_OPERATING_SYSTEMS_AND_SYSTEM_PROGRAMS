# Activity 7: Call Center Process Synchronization

## ภาพรวม
โค้ดชุดนี้จำลองระบบศูนย์รับสาย (call center) โดยใช้กระบวนการแยกเป็นสองโปรแกรม:
- `callcenter.c` ทำหน้าที่ประกาศและตรวจสอบสถานะของตัวแทนรับสายที่ว่างอยู่
- `customer.c` จำลองลูกค้าสายโทรเข้า ซึ่งต้องรอถึงจะมีตัวแทนว่างก่อนเริ่มคุย

ทั้งสองโปรแกรมสื่อสารกันโดยใช้ `named semaphore` ชื่อ `/callcenter` เพื่อควบคุมจำนวนลูกค้าพร้อมกันที่ตัวแทนสามารถรับได้

## `callcenter.c`

### ทำอะไร
- กำหนดจำนวนตัวแทน (`num_agents`) เริ่มต้นเป็น 2 ถ้ามีการส่งพารามิเตอร์บรรทัดคำสั่งจะใช้ค่าแทน
- สร้าง `named semaphore` ชื่อ `/callcenter` โดยตั้งค่าเริ่มต้นเป็นจำนวนตัวแทนที่พร้อมให้บริการ
- วนลูปไม่รู้จบ
  - อ่านค่าปัจจุบันของ semaphore ด้วย `sem_getvalue`
  - พิมพ์จำนวนตัวแทนที่ยังว่างอยู่
  - หน่วงเวลา 3 วินาที แล้ววนแสดงสถานะใหม่

### จุดสำคัญ
- `sem_open("/callcenter", O_CREAT, 0644, num_agents)` สร้าง semaphore ที่แชร์ได้ระหว่างกระบวนการ
- `sem_getvalue` ใช้เพื่อดูจำนวนทรัพยากรที่เหลืออยู่ (จำนวน agent ว่าง)

## `customer.c`

### ทำอะไร
- เปิด `named semaphore` เดียวกัน `/callcenter` โดยไม่สร้างใหม่
- ทำงานในลูปไม่รู้จบของลูกค้าที่โทรเข้า
  - รอสุ่ม 1-3 วินาทีก่อนโทรเข้าอีกครั้ง
  - พิมพ์ข้อความจำลองว่า "กดปุ่มสิบครั้ง และฟังเพลงรอสาย"
  - บันทึกเวลาเริ่มรอ
  - เรียก `sem_wait(sem)` เพื่อรอจนกว่าจะมีตัวแทนว่าง
  - เมื่อได้ตัวแทนแล้ว จำลองการสนทนาระหว่าง 3-5 วินาที
  - ปลดล็อก semaphore ด้วย `sem_post(sem)` เมื่อการสนทนาจบ
  - พิมพ์ข้อความจบการโทร

### จุดสำคัญ
- `sem_wait(sem)` ทำให้ลูกค้ารอจนกว่าจะมี agent ว่างก่อนคุย
- `sem_post(sem)` คืน agent ให้ระบบหลังจากคุยเสร็จ
- การตั้งเวลาก่อนและหลัง `sem_wait` ช่วยให้เห็นเวลาที่ลูกค้ารอจริง

## สรุปเชิงการทำงาน
- `callcenter.c` คือผู้ดูแลสถานะของ agent ว่าง โดยเผยค่าปัจจุบันออกมาทุก 3 วินาที
- `customer.c` คือ simulation ของลูกค้าที่เข้ามา และจะไม่เริ่มการโทรจนกว่า semaphore จะยืนยันว่ามีตัวแทนว่างอยู่
- ทั้งสองโปรแกรมใช้ `named semaphore` เป็นกลไกการซิงโครไนซ์ เพื่อป้องกันลูกค้าจำนวนเกินตัวแทนพร้อมกัน

## วิธีใช้งานเบื้องต้น
1. เปิด `callcenter.c` ก่อน เช่น `./callcenter` หรือ `./callcenter 3`
2. เปิดโปรแกรม `customer.c` หลายตัวในหน้าต่าง terminal แยกกัน
3. สังเกตข้อความว่า `callcenter` รายงานจำนวนตัวแทนว่าง และ `customer` รอหรือได้รับตัวแทนเมื่อว่าง
